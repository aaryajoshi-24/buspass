# 🚌 Bus Pass Management System

A web-based Bus Pass Management System developed using PHP and MySQL that allows students to apply for bus passes online and administrators to manage approvals efficiently.

---

## 📌 Features
- Student can apply for a bus pass
- View application status
- Admin login
- Admin approval of bus pass requests
- Simple and user-friendly interface

---

## 🛠️ Technologies Used
- HTML
- CSS
- Bootstrap
- PHP
- MySQL
- XAMPP (Apache Server)
